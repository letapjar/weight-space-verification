**Observations:**
- **Index mapping.** Line N of W1 is input N−1, so the cell (row r, column c) occupies inputs 5(10r+c) through +4. Interior cell (1,1) is inputs 55–59.
- **Wall ring.** Wall cells are always channel 3 and never have agent, moving, reward, or previous-frame activity, so their other weights never received gradient and sit at initialisation scale (mostly under 0.2). They carry no information.
- **Interior obstacle channel (channel 3) is unused.** Every checked interior channel-3 row is small. For example, input 58 (1,1,ch3) is `-0.039 0.023 -0.059 ... 0.192 ...`, with max |w| ≈ 0.19. Inputs 63, 68, 73 and 208–219 look the same.
- **Channels 0, 1, 2 and 4 are heavily used in the interior.** Input 55 (1,1,ch0) is `1.703 ... 1.670 6.706 ... -4.323`. Input 56 (1,1,ch1) is `-1.167 ... 1.306 -2.250 ... 2.035 -2.473`. Input 57 (1,1,ch2) is `-1.868 ... -2.195`. Input 59 (1,1,ch4) is `1.026 ... 2.015 -2.062 ... -3.183`. Large values recur across rows 1–8.
- **Previous-frame channel behaves like the current-frame channels.** In several hidden units, the agent and previous-frame weights for the same cell share a sign: unit 7 is 6.706 vs 0.757, unit 12 is -1.799 vs -1.601, unit 13 is -1.171 vs -3.183. That suggests the network reads occupancy plus history, i.e. motion or trail.
- **Output layer.** The biases are `[-0.853, 0.091, 0.212, 0.068, 0.382]`, so no-op is the least favoured a priori. W3 is large (up to about ±2.8), and the hidden layers are likely saturated. I cannot read a reliable up/down/left/right preference without running the forward pass.

The difference is that MinAtar Asterix has no wall ring, so the 8×8 border is probably this benchmark's framing.
