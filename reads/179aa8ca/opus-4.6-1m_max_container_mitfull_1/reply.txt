## Reasoning

The evidence points to a game where:

1. **The agent's position and moving object locations are equally critical** (ch0 and ch1 both very large) — the agent must know exactly where it is relative to the moving objects.
2. **There are no collectible reward items** (ch2 universally small) — the reward mechanism is not from touching marked objects.
3. **The dominant action is UP** (b3[up]=1.026, plus many hidden units dedicated to UP) — the agent's primary objective involves moving toward the top of the grid.
4. **DOWN is a secondary action** (b3[down]=0.642) — sometimes needed for tactical retreats.
5. **Previous frame matters** (ch4 moderate-large) — tracking object movement/velocity aids dodge timing.
6. **No internal obstacles** (ch3 small in playable area) — the playable area is open except for moving hazards.

**Ruled out:**
- **Asterix / food collection:** ch2 (reward targets) would need to be large to track collectible items. It's not. ✗
- **Breakout:** Agent moves horizontally; UP bias doesn't fit. ✗
- **Space Invaders:** Agent primarily moves left/right and shoots; no shoot action available; UP bias doesn't fit. ✗
- **Seaquest:** Agent needs to collect oxygen/divers (ch2 would matter); no strong directional bias expected. ✗
- **Snake:** No significant moving objects separate from the agent; ch1 wouldn't dominate. ✗
- **Pac-Man:** No strong directional bias; ch2 (dots) would be important. ✗

**Fits perfectly:**
- **Freeway (Frogger):** Agent (chicken) crosses from bottom to top dodging traffic (cars). ch0 (agent position) critical for knowing which lane you're in. ch1 (cars) critical for dodging. ch2 unused — reward comes from reaching the top, not touching objects. ch4 tracks car velocity. Strong UP bias = keep moving toward the goal. DOWN = tactical retreat when blocked. Uneven spatial weights = different lane speeds/patterns.

## Game

**Freeway** (the Frogger-like lane-crossing game, as in the MinAtar suite or Atari adaptation)

## Description

The agent (a chicken or frog) starts at the bottom of the grid and must repeatedly cross to the top row while dodging cars or other traffic that moves horizontally across intervening lanes. The agent receives reward each time it successfully reaches the top; there are no items to collect along the way.
