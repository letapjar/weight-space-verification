At (1,2), hidden unit 30: ch0 weight = −2.039, ch1 weight = +3.258 (opposite signs). This unit fires when a moving object is at that cell but the agent is not — i.e. it encodes "danger nearby but not collision," exactly the kind of feature needed for gap-timing in traffic.

## Reasoning

The critical pattern is:

| Channel | Role | Weight magnitude | Implication |
|---------|------|-----------------|-------------|
| 0 (agent) | Where am I? | Very large | Position-dependent strategy |
| 1 (moving objects) | Where are dangers? | Very large | Must react to moving things |
| 2 (reward targets) | Where is the prize? | Negligible | Reward is **not** from collecting objects |
| 3 (obstacles) | Where are walls? | Negligible | No internal walls; border is constant |
| 4 (previous frame) | What moved? | Moderate–large | Tracking velocity/direction of objects |

The **strong upward bias** (+1.026) means the agent's default goal is to move toward row 0 (the top). The positive down bias (+0.642) means it also regularly retreats. Left/right are used for lateral dodging.

**Ruled out:**
- **Snake** / **Pac-Man** / any collection game: ch2 (reward targets) would need large weights to find food/pellets. It doesn't.
- **Pong**: agent would be confined to one column; ch0 weights wouldn't vary across many columns as they do.
- **Pure dodge/survival**: no preferred direction, so no strong up bias.
- **Chase/tag**: moving objects would be targets (ch2 large), not dangers.
- **Maze/Sokoban**: ch3 (obstacles) would be large for internal walls.

The only game that fits all constraints — agent dodges moving objects, strong upward goal, no collectible rewards, open playfield, motion tracking matters — is a **road-crossing / lane-crossing game**.

## Game

**Freeway** (also known as Frogger)

## Description

The agent starts near the bottom of the grid and must cross to the top, dodging horizontally-moving traffic (cars/objects) that fills the lanes between. Reward is given for successfully reaching the opposite side; colliding with a moving object likely ends the episode or resets the agent.

## Confidence

**80%**
