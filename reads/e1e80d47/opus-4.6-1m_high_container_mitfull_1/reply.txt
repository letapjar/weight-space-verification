## Reasoning

The network has these distinctive signatures:

1. **The agent stays in column 1.** Channel 0 (agent position) has large, structured weights only at column-1 cells, with different patterns at different rows (encoding row-specific behavior). At all other columns, ch0 weights are noise-level. This means the agent moves vertically within a single column.

2. **Moving objects occupy columns 2–8.** Channel 1 (moving objects) has very large weights (up to 4.0) at columns 2–8 across multiple rows, but near-zero weights at column 1. Objects appear horizontally across the grid but not (or rarely) in the agent's column.

3. **The previous-frame channel tracks object velocity.** Channel 4 has large weights (up to ±3.7) at the same columns 2–8 positions. Combined with channel 1 (current positions), this lets the network infer direction and speed of horizontal traffic — critical for timing vertical movement through traffic lanes.

4. **Reward targets are not spatially informative.** Channel 2 is uniformly small everywhere, meaning the reward target is either fixed/predictable (always in the same place) or implicit. The agent doesn't need to look at ch2 to know where to go.

5. **No internal obstacles.** Channel 3 is small in the playable area; the only obstacles are the wall border. Moving objects are NOT coded as obstacles (the agent can enter their cells), consistent with a "pushback" or "penalty" mechanic rather than hard blocking.

6. **UP is the dominant action; left/right are unused.** The output bias strongly favors UP (1.676). The output weights treat left, right, and no-op as interchangeable (nearly identical W3 columns). The primary decision axis is UP vs DOWN, with many hidden units sharply opposing these two actions.

**What game fits all of this?**

- Agent moves vertically from bottom to top in a fixed column ✓
- Horizontal traffic (moving objects) crosses multiple lanes (rows) ✓
- Agent must time upward advances to avoid collisions ✓
- Default strategy is to press UP as much as possible ✓
- Left/right movement is useless (agent stays in one column) ✓
- Collisions don't create impassable obstacles (ch3 inactive for objects) ✓
- Reward comes from reaching the top, not from collecting scattered items ✓

**Ruled out:**
- **Pong**: no inherent UP bias; left/right irrelevant doesn't fit paddle tracking
- **Snake/collection games**: no directional bias; would need all four directions
- **Breakout/Space Invaders**: horizontal movement is critical
- **Dodge/catch**: agent would stay at bottom, not advance upward
- **Maze navigation**: would need all directions equally

## Game

**Freeway** (also known as road-crossing / Crossy Road–style game)

## Description

The agent (a "chicken") starts at the bottom of the grid and must cross to the top by moving upward through lanes of horizontal traffic. Cars move left/right across the rows; the agent times its upward advances to pass between cars, retreating or waiting when a car is approaching its column. Reaching the top of the grid gives a reward.
