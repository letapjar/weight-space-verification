# What these weights are: a hand analysis

I read all of it by eye, with no tools, so sums and correlations below are approximate. Indices are 0-based.

**Bottom line:** this is very probably a small policy network (500→32→32→5) that picks one of 5 discrete actions in a 10×10 walled grid game, where the input is a flattened 10×10×5 stack of binary feature planes. The geometry is solid; the identity of the game is not recoverable from weights alone.

## 1. The object

- It is an MLP with layers 500 → 32 → 32 → 5, about 17,250 parameters.
- The activation is not given; ReLU is assumed.
- The first layer is where the information is, because its rows fall into three sharply distinct types.

## 2. Three kinds of first-layer rows

| Kind | Count | Signature | Meaning |
|---|---|---|---|
| Untouched | 328 | Unstructured noise, σ ≈ 0.06, max about 0.24 | The input was zero in every training sample, so the row is still at initialisation |
| Bias clones | 44 | Row ≈ `b1` plus init noise (e.g. unit 10: 0.27–0.59 against `b1[10]` = 0.384) | The input was always 1, so it received exactly the bias's updates |
| Trained | 128 | Entries up to about ±9.8 | Inputs that actually vary |

Consequences:

- **Initialisation:** σ ≈ 0.063 = √(2/500), with tails well beyond the ±0.045 of PyTorch's default uniform. That fits He-normal or orthogonal init with gain √2.
- **Biases:** they started at about 0, since the clone rows match `b1` to within init noise.
- **Weight decay:** essentially none, because the dead rows have not shrunk.
- **Effective bias:** the 44 always-on inputs act as redundant biases, so the true bias of a hidden unit is about 45 × `b1` (roughly +17 for unit 10, −8 for unit 1).

## 3. Geometry: a 10×10 grid with 5 planes per cell

The row types repeat with the pattern index = 50·R + 5·C + k, where R and C run 0–9 and k is the plane.

| Plane k | Where it is ever non-zero | Behaviour |
|---|---|---|
| 3 | All of R=0 and R=9; C=0 and C=9 for R=1..8 | Constant: the border wall |
| 2 | Only C=9, R=1..8 (indices 97, 147, …, 447) | Constant: a fixed strip on one wall, on top of the wall bit |
| 0 | Only C=1, R=1..8 (55, 105, …, 405) | Variable |
| 1 | Only C=2..8, R=1..8 | Variable |
| 4 | All 64 interior cells | Variable |

- The interior is an open 8×8 room: no interior walls ever appear.
- The planes are multi-hot, not a one-hot category: the C=9 cells have planes 2 and 3 both on.
- Interior cells have at least three states. If a cell were strictly "plane 1 or plane 4", the two rows would be near-negatives of each other; they are not.
- I cannot tell whether R is y and C is x or the reverse, so "vertical" below means "along R".

## 4. Fine structure in the trained rows

**Plane 0 is a single entity sliding along C=1, compared against nearby plane-1 objects.** Several hidden units are step functions across the midline (R 1–4 versus 5–8), with opposite signs for the two planes:

| Unit | Plane 0 at C=1, R=1..8 | Plane 1 at C=2, R=1..8 |
|---|---|---|
| 7 | −0.2, +2.0, +2.1, +0.8, +0.3, −1.1, −1.6, −3.1 | −4.6, −4.9, −3.8, −4.2, +3.4, +2.3, +2.6, −0.2 |
| 2 | +2.2, −0.7, +1.1, +1.2, +0.2, −0.7, −2.5, −2.0 | −2.6, −3.3, −3.2, −0.6, +4.3, +6.3, +4.3, +1.9 |
| 19 | −1.6, −1.3, −0.8, −0.2, −0.2, +0.3, +0.5, +0.7 | +0.7, +4.3, +6.0, +6.0, −0.8, −1.5, −8.2, −2.6 |

- The same steps continue at C=3 (unit 7: −3.5, −2.4, −3.7, −2.9, 0.0, +2.9, +4.2, +3.1) and fade by C=4–5.
- These units compute "nearby plane-1 objects are above or below the plane-0 entity". That is what a controlled agent confined to one lane needs in order to line up with or dodge approaching objects.
- Plane-1 rows have the largest norms at C=2–3 (about 18 for index 61) and the smallest at C=8, so proximity to the C=1 lane sets importance.

**Plane 4 is a second dynamic object class.**

- At C=8 its weights nearly copy plane 1's in every row (e.g. 91 vs 94, 341 vs 344, 441 vs 444). Far from the agent, the two types are interchangeable "something is coming in this row".
- At C=1 its weights are a positively correlated, often scaled-down copy of plane 0's (105 vs 109, 355 vs 359). That suggests it appears there mostly where the agent is.
- In between, its weights are patchy and lack plane 1's clean steps.

**Plane 1 never appears at C=1.** These objects are removed, or the episode ends, before they are ever observed in the agent's lane.

## 5. Output side

- `b3` sums to about −0.06, and output columns are strongly antagonistic (output 1 against 0, 3 and 4). That is the zero-sum signature of softmax cross-entropy logits; Q-values would share a common value component.
- Output 1 has net positive weights (column sum about +14), so it looks like the default choice. Output 2 has small, mostly negative weights and bias −1.28, so it is rarely chosen.
- A crude linear trace gives output 4 about +18 from unit 7 and about −8 from unit 19, so it is probably one of the two moves along R. I could not reliably label the others.

## 6. Hypotheses and verdicts

| Hypothesis | Verdict | Why |
|---|---|---|
| Image, tabular or embedding classifier | Ruled out | Exact 50/5 periodicity, a wall frame, and 66% never-active inputs |
| 10 stacked frames or entities of 50 features | Ruled out | Blocks 0 and 9 differ from blocks 1–8 in exactly the way a 2-D border requires |
| One-hot cell category including "empty" | Ruled out | Two bits on at C=9; no complementary row pairs |
| Planes 0, 1, 2 are one object type renamed by column | Ruled out | Planes 0 and 1 enter the comparator units with opposite signs |
| Two-player board game (Othello, checkers) | Unlikely | Only 5 outputs, column-restricted planes, a lane-bound entity |
| Free-roaming navigation agent on plane 4 | Possible but weaker | The clean ordinal position code is on plane 0, not plane 4 |
| Q-network | Less likely | The zero-sum output biases and antagonistic logits point to softmax, though this is not conclusive |
| Policy for a lane-based arcade game | Best fit | Everything in sections 3–5 |

## 7. Best explanation

This is the actor (trained by policy gradient or by imitating an expert) for a small arcade-style gridworld with 5 actions. The observation is a 10×10 board flattened as (line, cell, plane):

- **Plane 3:** border walls.
- **Plane 2:** a static strip along the far wall, such as a spawn or goal line.
- **Plane 0:** the controlled entity, confined to the lane next to the opposite wall and moving only along it.
- **Plane 1:** objects that live in the other seven lanes and matter most within 2–3 cells of the agent; they are probably hazards or enemies arriving from the far side.
- **Plane 4:** a second moving class that can be anywhere, including on the agent; candidates are pickups, projectiles or motion trails.

This resembles a sideways shooter, a catch-and-dodge game or a lane-defence game. The exact game, the board orientation, and the action labels are guesses.
