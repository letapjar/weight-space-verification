**What this is:** the weights of a small fully connected network (500 → 32 → 32 → 5, about 17k parameters) that looks like a trained policy for a Frogger-style "cross the road" gridworld. I worked this out by reading the weights only; nothing was run, so the game interpretation is inference, with the weaker parts flagged below.

## Input layout: a 10×10 grid with 5 channels per cell

The 500 inputs decode as `i = 50*row + 5*col + channel` (0-indexed). The rows of W1 fall into three clear types:

- **Never-active inputs (about 296 rows):** small noise with std ≈ 0.065, which matches He-normal initialisation √(2/500). These received no gradient, so the input was always 0. This also suggests ReLU hidden units and no weight decay.
- **Always-on inputs (44 rows):** each is nearly a copy of `b1` plus init noise (compare input 3 with `b1`). An input that is always 1 gets the same gradient as the bias, so these are constant features.
- **Varying inputs (about 160 rows):** large trained weights, up to about ±11.

Where each type sits gives the map:

| Channel | Where it is active | Likely meaning |
|---|---|---|
| 3 | Always on for the whole border (row 0, row 9, col 0, col 9) | Wall |
| 2 | Always on for row 1, cols 1–8 | Goal strip (the agent is never observed there, so reaching it likely ends the episode) |
| 0 | Varies in rows 2–8, cols 1–8 | Agent |
| 1 | Varies in rows 2–7 only | Cars / obstacles |
| 4 | Varies in rows 2–8 | Motion trail (previous position), most likely |

Empty cells are all zeros, so this is not a strict one-hot encoding.

## The game the weights imply

- **Six traffic lanes (rows 2–7), two cars per lane.** In every lane the channel-1 weights at column c and c+4 are identical up to init noise (inputs 106≈126, 111≈131, 156≈176, 161≈181, 206≈226, 256≈276, 306≈326, 356≈376, and so on). Those inputs always fire together, so each lane has cars 4 apart, wrapping around the 8-wide road, with 4 possible phases.
- **Lanes 2 and 6 move one cell per step toward higher columns.** There, channel 4 at column c is close to a copy of channel 1 at column c+1, including the wraparound (109≈111, 139≈141, 144≈106, 309≈311, 344≈306). That is a trail one cell behind each car.
- **Lanes 3, 4, 5 and 7 are different.** Channel 4 is still 4-periodic but is not a shifted copy of the cars. My best guess is that these lanes move at a different speed or timing, so the trail carries extra timing information; I could not confirm this.
- **Row 8 is a safe start row.** It has no cars. Channel 4 at (8,c) tracks "agent at (7,c)" (input 429 ≈ input 375; also 434≈380), which is the agent's own trail after stepping from row 8 to row 7. So the agent travels from row 8 toward row 1.
- **The agent stays mostly in the middle.** Agent-channel weights are by far the largest (input 315 → unit 0 is 11.27; inputs 365, 370, 375, 420, 425 reach ±10). They peak in columns 3–5 and fade toward the edges, especially column 8.
- **Lanes 2 and 6 look partly synchronised.** Their car weights resemble each other (121≈321, 106≈306 on many units), hinting at a fixed or shared starting layout.

If the grid was flattened column-major instead of row-major, the picture is simply transposed (traffic vertical, agent crossing sideways).

## Hidden layers and outputs

- **Effective biases are large.** With 44 always-on inputs, each first-layer unit's real offset is roughly 45 × `b1`. Some units sit far negative and fire only on specific configurations (units 1, 20, 27); others are almost always on (units 12, 15, 21).
- **Two first-layer units are barely used.** Units 5 and 21 have almost no large input weights.
- **W2 is dense** with no structure I could read by eye.
- **The 5 outputs are most plausibly action scores** for stay/up/down/left/right. W3 has no common component across outputs, which fits policy logits better than Q-values, but this is low confidence.
- **I cannot tell which output is which action** without running the network. Output 2 has the most negative bias (−1.28) and generally small weights, so it is probably the rarely used action (plausibly "move backward"). Outputs 1 and 4 are often opposed in W3 (hidden unit 1: +3.69 vs −3.46), suggesting opposite actions.
